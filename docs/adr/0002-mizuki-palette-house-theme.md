# Mizuki palette as the house theme

Akiyama Mizuki's palette — official image color Thistle #DDAACC, Hair Pink #F4A9C6, Deep Ribbon #8E3B5C, Uniform Gray #A2A6BD — on a Dark Niigo Night base (#1E1B26 background, #2A2433 surface, #F4E3EB foreground) is the shared color scheme for bash (custom `mizuki` OMB theme via stowed OSH_CUSTOM), tmux (statusline/borders, still plugin-free), nvim (hand-rolled `lua/custom/mizuki.lua`, zero new plugins), and Ghostty (custom `themes/mizuki`, unconditional `theme = mizuki`), because a single versioned palette keeps all four tools visually coherent with no new dependencies and no install.sh changes (stowed files only), accepting that bright ANSI slots are systematic tints, Ghostty cyan is a derived steel-blue with no canon anchor, and GNOME light/dark no longer swaps the terminal since the rest of the scheme is dark-only.
